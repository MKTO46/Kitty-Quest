# Kitty Quest — browser edition

Open `index.html` in a modern browser. The app works without a server and saves progress only in that browser on that device.

The starter plan is preloaded around your school days: Monday/Wednesday and Tuesday/Thursday include the two-hour school-to-gym drive; Friday and Saturday have gym blocks; Sunday is explicitly an at-home training day.

The **Train** tab is the Phase 3 workout tracker. Every exercise includes its target, alternatives, progression, and local set/rep/weight/note logging. If equipment, load, difficulty, or discomfort blocks a movement, choose **Can't do this?** to substitute an appropriate backup—without losing the session.

For an installable offline app on iPhone, host this folder with any static web host (or open it through a local web server), visit it in Safari, then choose **Share → Add to Home Screen**. No account, internet API, or cloud sync is used.

To reset the demo data, clear the browser data for the page/site.
